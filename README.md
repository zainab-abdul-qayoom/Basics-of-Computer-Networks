# Basics of Computer Networks

This repository is where I am keeping my Computer Communication and Networks lab work from university. Every practical is done using Cisco Packet Tracer, a free network simulator, and for each one I add the actual Packet Tracer file along with a simple notes PDF explaining what was done, why it was done, and the terms involved. The notes are written in plain language since I started this course with very little networking background, so they double as revision material and interview or viva preparation for me later.

## Tools Used

Cisco Packet Tracer, a network simulation tool that lets you build and test computer networks virtually without needing real hardware.

## How to Open the .pkt Files

Download Cisco Packet Tracer from the Cisco Networking Academy site, install it, then open any .pkt file from this repo directly inside the application to see the exact setup used.
